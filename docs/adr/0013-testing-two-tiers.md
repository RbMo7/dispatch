# Testing: real RPC calls for Chain Handlers, pure-unit tests for chain-agnostic logic

The reference implementation's discipline — no fake Chain Handler, real Sandbox/testnet RPC calls in its integration tests — caught real bugs a mock couldn't (e.g. a "Blockhash not found" failure discovered only at real volume against the public Solana devnet RPC). That discipline carries over for Chain Handler behavior specifically, since that's exactly where this project's differentiating, hard-won bugs live. It's paired with fast, pure-unit tests for everything with no I/O — Retry Policy's stuck/`ABANDONED` timeout decisions, batching/chunking math, the Coordinator's orchestration logic tested against the fake repository from ADR-0011. Two tiers, not a single blanket policy either way.
