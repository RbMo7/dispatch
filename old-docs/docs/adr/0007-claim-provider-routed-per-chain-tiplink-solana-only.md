# Claim Provider is routed per chain: real TipLink for Solana, local keypair for Base

Ticket 08 shipped with `LocalKeypairClaimProvider` for every chain — a genuine transfer to a throwaway wallet nobody could actually claim into. Real TipLink integration (`@tiplink/api`) replaces that for Solana: `TipLink.create()` is pure offline cryptography (a random seed run through a KDF into a Solana keypair, with the seed encoded in the claim URL's fragment — "the link is the wallet"), needing no API key or network call, verified live end-to-end including an independent `TipLink.fromUrl()` round-trip that rehydrates the exact funded address from the URL alone.

TipLink has no EVM equivalent — it's a Solana-specific product. Rather than block the whole feature on that, or fake an "EVM TipLink" that doesn't exist, `ChainRoutedClaimProvider` dispatches per chain: Solana gets the real `TipLinkClaimProvider`, Base keeps the existing `LocalKeypairClaimProvider` fallback. Adding this required zero changes to the `ClaimProvider` interface, `resolveClaimRecipients`, or anything downstream — the same extensibility pattern as the Signing Provider swap in ADR-0006.

Consequence: a Base claim payment still lands in a wallet nobody can claim into (ADR-0005's limitation stands for that chain specifically). If Base ever needs a real claim UX, the fix is a new `ClaimProvider` implementation for it, not a change to this routing.

**Future direction, not built now**: TipLink's mechanism (random seed → KDF → derive a keypair, secret embedded in the link) is chain-agnostic in principle — the same seed could derive a Base/secp256k1 key as easily as a Solana/ed25519 one, which would let one link resolve to real wallets on multiple chains at once. Deliberately not pursued now: it's security-sensitive code (the link is a bearer secret) better built on a proven primitive than invented under time pressure, and — the bigger gap — TipLink's real value includes a hosted claim page (`tiplink.io`) that a self-hosted equivalent would have to build from scratch. Staying on `tiplink.io` for Solana until there's a real reason and real time to self-host a multi-chain version.
