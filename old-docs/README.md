# Old docs — frozen snapshot from `dispatch`

This folder is a preserved copy of the original `dispatch` repo's documentation, at the point this project diverged into `dispatchxyz`. It describes a different, earlier product (a multi-tenant SaaS disbursement platform, with a Decision Engine, Privy/password dashboard auth, and per-tenant wallets) — that product stays archived in the `dispatch` repo and is **not** what `dispatchxyz` is building.

Kept here purely as historical reference — for provenance, and because some of it (e.g. the chain-execution and nonce-management reasoning in ADR-0002, ADR-0003, ADR-0006, ADR-0010) genuinely informed `dispatchxyz`'s own founding decisions (see `../docs/adr/`). Nothing in this folder should be treated as current documentation of `dispatchxyz` itself — that's `../CONTEXT.md`, `../docs/concept.md`, and `../docs/adr/`.

Copied from `dispatch` at commit `d5c6d241ce01192ac462689e41616e1717a67d1f` (plus a small amount of then-uncommitted working-tree edits to `CONTEXT.md`, `ONBOARDING.md`, and `docs/adr/0009`), on 2026-09-21.
